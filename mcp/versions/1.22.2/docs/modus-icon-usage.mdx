# Modus Icon Usage

`modus-wc-icon` can render **Modus Icons 1.0** ligatures or **Modus Icons 2.0** glyphs from `@trimble-oss/modus-icons-css`. The `version` prop selects the set (`'1.0'` by default). Names that exist in only one set fall back to that set in both versions.

Because fallback can emit either markup, load **both** the 1.0 font sheet and a 2.0 sheet in the general case. For 2.0, choose **one** delivery mode: CSS mask (recommended) or icon font. Do not load both 2.0 modes on the same page — they share `.modus-icon-*` class names but paint differently.

## Name resolution

The `version` prop is `'1.0'` or `'2.0'`. Hyphen or underscore is accepted for 1.0 names (`add_bold` and `add-bold` both resolve).

## 1. Modern browsers (CSS mask, recommended)

Mask sheets tint with `color` / `currentColor`. Import regular for outlined icons and fill if you use `variant="solid"`.

### From the Web Components package

```js
import '@trimble-oss/moduswebcomponents/modus-icons-2.css';
```

Or load only the sets you need:

```js
import '@trimble-oss/moduswebcomponents/modus-icons-regular.css';
import '@trimble-oss/moduswebcomponents/modus-icons-fill.css';
```

### From `@trimble-oss/modus-icons-css` directly

```bash
npm install @trimble-oss/modus-icons-css@0.10.0
```

```js
import '@trimble-oss/modus-icons-css/css/modus-icons-regular.min.css';
import '@trimble-oss/modus-icons-css/css/modus-icons-fill.min.css';
```

### CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons-css@0.10.0/css/modus-icons-regular.min.css"
/>
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons-css@0.10.0/css/modus-icons-fill.min.css"
/>
```

Regular is about 109 KB gzipped; fill is about 182 KB gzipped. Skip fill if you never use `variant="solid"`.

## 2. Legacy browsers without CSS mask (icon font)

Use this **instead of** the mask sheets, not in addition to them. Markup and class names are unchanged — only the `<link>` differs.

Font glyphs are single-color and stroke-traced. True duotone requires the mask path.

```js
import '@trimble-oss/moduswebcomponents/modus-icons-2-font/css/modus-icons-font-regular.css';
import '@trimble-oss/moduswebcomponents/modus-icons-2-font/css/modus-icons-font-fill.css';
```

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons-css@0.10.0/css/modus-icons-font-regular.css"
/>
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons-css@0.10.0/css/modus-icons-font-fill.css"
/>
```

If you copy files into `public/`, keep the package layout so the font CSS `url("../fonts/{regular,fill}/...")` paths still resolve:

```
public/
  └── modus-icons-2-font/
      ├── css/
      │   ├── modus-icons-font-regular.css
      │   └── modus-icons-font-fill.css
      └── fonts/
          ├── regular/
          └── fill/
```

## 3. 1.0 ligature font

Required for 1.0 ligatures, including unmapped names and the default `version="1.0"` path. There are 162 unmapped 1.0 names with no 2.0 slug.

### Option A: Online usage (CDN)

Create a file at:

```
/public/modus-web-components/modus-icons.css
```

with the following contents:

```css
@font-face {
  font-family: 'modus-icons';
  src: url('https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons@1/dist/modus-outlined/fonts/modus-icons.woff2')
    format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

@font-face {
  font-family: 'modus-icons-outlined';
  src: url('https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons@1/dist/modus-outlined/fonts/modus-icons.woff2')
    format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

@font-face {
  font-family: 'modus-icons-solid';
  src: url('https://cdn.jsdelivr.net/npm/@trimble-oss/modus-icons@1/dist/modus-solid/fonts/modus-icons.woff2')
    format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

.modus-icons-outlined {
  font-family: 'modus-icons-outlined';
  font-style: normal;
  font-weight: normal;
}

.modus-icons-solid {
  font-family: 'modus-icons-solid';
  font-style: normal;
  font-weight: normal;
}

.modus-icons {
  font-family: 'modus-icons';
  font-style: normal;
  font-weight: normal;
}
```

Then include it in your app:

```html
<head>
  <link rel="stylesheet" href="/modus-web-components/modus-icons.css" />
</head>
```

The Web Components package also exports this sheet as `@trimble-oss/moduswebcomponents/modus-icons.css`.

### Option B: Offline usage

1. Install the 1.0 Modus Icons package:

```bash
npm install @trimble-oss/modus-icons
```

2. Download the font files:

```
node_modules/@trimble-oss/modus-icons/dist/modus-outlined/fonts/modus-icons.woff2
node_modules/@trimble-oss/modus-icons/dist/modus-solid/fonts/modus-icons.woff2
```

3. Create this directory structure in your project:

```
public/
  └── modus-web-components/
      ├── fonts/
      │   ├── modus-icons-outlined.woff2  (renamed from modus-outlined/fonts/modus-icons.woff2)
      │   └── modus-icons-solid.woff2     (renamed from modus-solid/fonts/modus-icons.woff2)
      └── modus-icons.css
```

4. Create a modified `modus-icons.css` file that references the local font files:

```css
@font-face {
  font-family: 'modus-icons';
  src: url('./fonts/modus-icons-outlined.woff2') format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

@font-face {
  font-family: 'modus-icons-outlined';
  src: url('./fonts/modus-icons-outlined.woff2') format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

@font-face {
  font-family: 'modus-icons-solid';
  src: url('./fonts/modus-icons-solid.woff2') format('woff2');
  font-style: normal;
  font-weight: normal;
  font-display: swap;
}

.modus-icons-outlined {
  font-family: 'modus-icons-outlined';
  font-style: normal;
  font-weight: normal;
}

.modus-icons-solid {
  font-family: 'modus-icons-solid';
  font-style: normal;
  font-weight: normal;
}

.modus-icons {
  font-family: 'modus-icons';
  font-style: normal;
  font-weight: normal;
}
```

5. Include the CSS file in your HTML just as in the online version:

```html
<head>
  <link rel="stylesheet" href="/modus-web-components/modus-icons.css" />
</head>
```

## 4. Usage in components

Once the stylesheet is loaded, you can use icons in any framework:

### Web Components

```html
<!-- Outlined 2.0 icon from a 1.0 alias -->
<modus-wc-icon name="alert" variant="outlined"></modus-wc-icon>

<!-- Solid 2.0 icon -->
<modus-wc-icon name="alert" variant="solid"></modus-wc-icon>

<!-- Native 2.0 slug -->
<modus-wc-icon name="ship"></modus-wc-icon>
```

### React

```tsx
import { ModusWcIcon } from '@trimble-oss/moduswebcomponents-react';

export function IconExamples() {
  return (
    <div>
      {/* Outlined */}
      <ModusWcIcon name="alert" variant="outlined" />

      {/* Solid */}
      <ModusWcIcon name="alert" variant="solid" />

      {/* Accessible icon */}
      <ModusWcIcon
        name="accessibility_circle"
        variant="solid"
        decorative={false}
        aria-label="Accessibility features"
      />

      {/* Custom styling */}
      <ModusWcIcon
        name="add_bold"
        variant="outlined"
        decorative
        style={{ color: 'var(--modus-wc-color-trimble-blue)' }}
      />
    </div>
  );
}
```

### Angular, Vue, etc.

Follow the same approach — include the 2.0 stylesheet once, plus the 1.0 sheet if you still render unmapped 1.0 names.
