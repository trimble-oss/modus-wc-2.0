# Offline theme generator

Edit `modus-theme.config.json` in your app and run `npx modus-theme build`.
Do not copy CSS out of this playground.

Open the [live JSON preview](/theme-generator/index.html) (import/export JSON
only). Token contract and slot routing: see `docs/custom-themes.md`.
