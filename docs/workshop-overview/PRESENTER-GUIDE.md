# Designing with Agent — presenter guide

The React deck is visual. You speak. Slides only reveal objects.

## Controls

- Click, Space, or → reveals the next object.
- ← or **Back** reverses one object.
- **Assessment** opens a modal you can close with Close, backdrop, or Escape.
- The Playwright detour has no assessment.

## Slide 1 — Agents window

Show the Agents window, then the user bubble, then the Agent bubble, then the preview pane. Do not open the terminal. Ask Agent to open what it built.

## Slide 2 — Concentric layers

Innermost ring is binary. Then language, IDE, Agent. Code still exists underneath. Participants now direct outcomes.

**Assessment 1:** basic web page, Agent opens it.

## Slide 3 — Smart intern

Intern appears, knowledge orbits, intern drifts, guide/compass locks the path. Then five prompt chips: Goal, Audience, Context, Requirements, Success.

## Slide 4 — Frameworks

Component, state, event, same list updating, then React as the workshop vehicle. They need the name, not the syntax.

**Assessment 2:** richer React app with one state change.

## Slide 5 — Rules

A prompt sticky note is one chat. The rule board stays.

## Slide 6 — Skills, MCP, Figma

Playbook, plug, Figma frame. The Figma object links to [https://www.figma.com/mcp-catalog/](https://www.figma.com/mcp-catalog/).

## Slide 7 — Context stack

Prompt, Rules, Skills, MCP/Figma stack together.

**Assessment 3:** connect workshop context and build in the shared folder.

## Slide 8 — Detour: Playwright MCP

Live demo. Objects: Playwright MCP card → Connect in Cursor → Site → Scrape → Ask Agent.

Use [https://playwright.dev/docs/getting-started-mcp](https://playwright.dev/docs/getting-started-mcp).

Demo script:

1. Open the Playwright MCP getting-started page.
2. Add Playwright MCP in Cursor.
3. Ask Agent to open a public site and extract the useful structure.
4. Show that Agent can now scrape without a custom MCP from scratch.
